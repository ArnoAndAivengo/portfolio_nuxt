## Зачем вообще тройной трек

Обучаясь новому ЯП или технологии я всегда стараюсь проходить через математические примеры.
Плюс встречаются англ. слова, из технического лексикона, которые ранее не слышал.
Новое англ. слово хочется изучить, послушать как произносится и записать в словарик.
Вот и было решено совместить в уроках ЯП, англ. язык и математику.

Обычная схема LMS: отдельный курс по ЯП, отдельный — по английскому, ещё один — «математика для программистов».
Это все нужно. Но, ученик прыгает между курсами, а связи между темами почти нет.

В LearnPortal все это вместе будет в одном уроке:

1. **Язык программирования** — синтаксис, идеи, практика в редакторе.
2. **Иностранный язык** — лексика и термины прямо в тексте урока.
3. **Школьный предмет** — сюжет задач: математика, физика, химия, литература… в любом предмете есть математическая составляющая.

За один урок ученик решает одну задачу, в которой уже вшиты все три направления.

## Пилот: ЯП + математика + английский

На первое время реализуется стартовый набор **ЯП + математика + английский**

Английский и так сидит в ключевых словах любого ЯП: `const`, `let`, `function`, `return`, `def`.
Математика даёт базу для изучение любого ЯП.

## Как это выглядит в Markdown

Стек контента я уже описывал в [выпуске про Markdown](/articles/learnportal-tehblog-02): файлы в git → sync в PostgreSQL → плеер.
Тройной трек живёт внутри тех же файлов.

- **Программирование** — теория, quiz, практика, homework как обычно.
- **Английский** — глоссы вида `(variable)` рядом с термином; плеер умеет озвучить их через Web Speech API.
- **Предмет** — сюжет задачи: сторона прямоугольника, сумма катета и т.д. Из математики, алгебры, дискретной математики.

Методисту не надо открывать три файла, он пишет один урок. 
Правила для авторов фиксируют, что глоссы и предметный сюжет обязательны.

## Озвучка глоссов в плеере

В плеере рядом с английским глоссом находится кнопка произношения 🔊. 
Источник звука — Web Speech API (`en-US`), без отдельных аудиофайлов.

- в теории и практике — первое вхождение слова в блоке;
- в quiz — глоссы в вопросе и вариантах ответа;
- в Markdown достаточно только текста глосса, файлы урока не раздуваются от медиа.

## Итог

Тройной трек довольно удобная база для подтягивания школьной базы.

- один урок качает код, язык и предметную базу;
- у автора урока появляется возможность дать интересный пример;
- озвучка глоссов уже в плеере — без облачного TTS.
