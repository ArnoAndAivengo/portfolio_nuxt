Python завоевал рынок обучения как лаконичный и лёгкий в освоении ЯП.
Во всех школах начальное программирование — это Python.
Его синтаксис простой: без лишних скобок, точек с запятой и громоздких объявлений типов.
Именно поэтому Python стал главным ЯП в IT,
превратившись в стандарт де-факто для обучения программированию по всему миру.

## Синтаксис

Синтаксис Python часто называют «выполняемым псевдокодом».
Его главная фишка в том, что код пишется и читается почти как обычный язык.
Разработчики избавились от всего визуального шума, который перегружал программы прошлых поколений.

На русском:

```
для каждого числа в списке:
    если число чётное:
        добавить его в результат
```

На Python это почти тот же текст:

```
result = []
for n in numbers:
    if n % 2 == 0:
        result.append(n)
```
Именно благодаря такому синтаксису Python экономит время:
разработчик тратит энергию на решение бизнес-задачи,
а не на обслуживание синтаксических правил самого языка.
